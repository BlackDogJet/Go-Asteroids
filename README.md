# Go-Asteroids
An asteroids clone written in Go using [raylib](https://www.raylib.com/).

## Motivation
To write an asteroids clone in Go.

## ⚙️ Installation
```bash
Go to [raylib GitHub](https://github.com/raysan5/raylib) under build and installation. Install the required dependencies for your platform.

Inside a Go module:

Go get github.com/BlackDogJet/Go-Asteroids

```

## 🤝 Contributing

Go to [raylib GitHub](https://github.com/raysan5/raylib) under build and installation. Install the required dependencies for your platform.

### Clone the repo

```bash
git clone https://github.com/BlackDogJet/Go-Asteroids.git
cd Go-Asteroids
```

### Build the compiled binary

```bash
go build
```

### Submit a pull request

If you'd like to contribute, please fork the repository and open a pull request to the `main` branch.
